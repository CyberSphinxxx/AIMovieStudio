# Measurable milestone exit gates

## Phase 0 research
- [ ] Actual Windows OS, driver, GPU free VRAM, 16 GB RAM and disk confirmed
- [ ] WanGP current API/version and Community License conditions documented
- [ ] Candidate model card and model-weight usage license checked
- [ ] Model download size and approval handled explicitly
- [ ] Provider decision recorded with reasons or marked BLOCKED

## Phase 1 app shell
- [ ] One idea creates persisted project without requiring API key
- [ ] Mode + duration + orientation validated, portrait UI responsive
- [ ] First-run demo clearly labeled, diagnostics available
- [ ] Reopen project after server restart, tests pass

## Phase 2 story
- [ ] Complete finite series ending is determined and persisted
- [ ] Script, episodes, locations, characters, facts have stable IDs
- [ ] Episode 2 retains episode 1 outcome across process restart
- [ ] Contradictory cast/prop state flagged
- [ ] JSON errors repaired or clearly surfaced with bound attempts

## Phase 3 images
- [ ] Character/setting references automatically generated/persisted
- [ ] Shot keyframe references use pinned entity versions
- [ ] Real local image provider tested separately from demo
- [ ] User can regenerate a reference with lineage

## Phase 4 worker
- [ ] Job event stream, pause/resume/cancel, max retry works
- [ ] Hard-kill and resume preserves completed stage outputs
- [ ] OOM, disk full, corrupt video and model missing handled
- [ ] GPU job semaphore and disk quota measured

## Phase 5 video
- [ ] WanGP or other backend adapter uses documented official surface
- [ ] Two short real generations on RTX 3060 6 GB/16GB verified and logged
- [ ] Portrait and landscape supported directly or honest fallback
- [ ] If impossible: real-provider stage BLOCKED, no success masquerade

## Phase 6 sound/export
- [ ] Stable per-character voice and accurate line audio
- [ ] Mixed SFX/ambience/licensed music or valid no-music path
- [ ] ffprobe verified portrait and landscape MP4, subtitles sidecar
- [ ] Safe file output and clean audio timings

## Phase 7 usability
- [ ] Single click orchestrates full movie with minimal choices
- [ ] Full series episode and continuation works from saved canon
- [ ] User can inspect shots and fix any one clip
- [ ] Error messaging, mobile/responsive screenshots, accessibility pass

## Phase 8 release
- [ ] Clean Windows install and launcher works
- [ ] Rights/security audit, no forced online accounts or fees
- [ ] Tests and real/mock distinctions reported honestly
- [ ] Documentation, repair and backup controls complete
