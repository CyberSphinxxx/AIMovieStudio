# Example production acceptance input

Project from `sample_project.json`: 6 episodes, 60 seconds each, 9:16. The lantern glows only when the protagonist holds it; the shadow only moves when the lantern flickers. The showrunner must establish the shadow origin and decide a final resolution before episode 1 is scripted. The same courier character appears in every episode with pinned identity, same coat and voice until a plot event changes them. Each episode should have a short hook, coherent ending/cliffhanger and full script. A restart after Episode 1 must not erase episode plan or approved canon. Test both DEMO and REAL media paths separately.

## Failure injections
- Force the shadow to appear in bright lantern light without explanation; must report world-rule violation.
- Insert an out-of-order character death/revival; must report continuity conflict unless event resolves.
- Change project to 16:9; shot keyframes must be reframed/re-generated with output still matching target.
- Kill worker after shot 3; on restart same hashes for first 3 clips, resume remainder.
